# My Blog Portfolio

2022년에 제작한 개인 블로그를 최신 기술 스택으로 재구축하는 학습 프로젝트입니다. Java와 Spring Boot를 학습하며 서비스의 설계부터 구현, 테스트, 배포까지 전 과정을 직접 경험하는 데 목적을 둡니다.

## 프로젝트 목표

- Spring Boot 기반 웹 애플리케이션 개발
- Docker Compose와 MySQL 연동
- 게시글 CRUD 구현
- 자동 테스트 작성
- GitHub Actions를 통한 CI/CD 구축
- AWS 배포

## 현재 진행

- Spring Boot 기본 프로젝트 생성
- 첫 웹페이지 실행
- Docker Compose 및 MySQL 연결
